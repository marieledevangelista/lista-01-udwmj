# lista-01-udwmj
Lista de Exercícios I - Desenvolvimento Web
## Código em JavaScript

O código calcula a média de duas notas. Primeiro são definidas as duas notas e depois é feito o cálculo da média.

Depois, utilizando if e else, o programa verifica se a média é maior ou igual a 7. Se for, mostra que o aluno foi aprovado. Caso contrário, mostra que o aluno foi reprovado.
